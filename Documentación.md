Panadería 



Sistema de Integración y análisis de datos de ventas.



Aplicación desarrollada en Java para integrar, Validar y analizar registros de ventas de una panadería.



Formato de entrada: CSV,JSON y XML



Base de datos: PostgreSQL 



Objetivo Procesar Información de Ventas y generar reportes estadísticos.
